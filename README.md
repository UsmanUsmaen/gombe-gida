# TECTOPI.COM App Prototype

A lightweight, static web app prototype for **TECTOPI.COM**.

## Features

- Responsive marketing-style landing page.
- Services and featured projects sections.
- Client-side rendered projects list.
- Contact form with built-in validation + success feedback.
- Theme toggle (dark/light mode).

## Run locally

```bash
python3 -m http.server 4173
```

Then open <http://localhost:4173>.
